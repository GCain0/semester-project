# Project Proposal: Preparing for Childbirth Resource Site

## 1. Project Description

My project is a **childbirth preparation website** designed to help expecting parents get organized, informed, and emotionally ready for labor, delivery, and the first days at home with a newborn. The site will include practical checklists, guidance on what to pack, timelines for preparation, and supportive information for both birthing parents and partners. Visitors will experience a calm, reassuring, and easy‑to‑navigate resource that breaks down a stressful life event into manageable steps.

This project matters because preparing for childbirth can feel overwhelming, especially for first‑time parents who may not know what to expect or what they truly need. It is especially meaningful for **me and my wife**, as we are preparing for the arrival of our child and want a clear, organized resource to help us stay ready and confident. The intended audience includes expecting parents, partners, and support people who want reliable, simple, and actionable information as they get ready for the birthing process.

---

## 2. Feature Plan

### Project 01 – Prototype (Week 05)
- **Homepage overview:** A welcoming landing page explaining the purpose of the childbirth preparation site.  
- **Hospital bag checklist:** A simple list of essentials for the birthing parent, partner, and baby.  
- **Birth timeline:** A basic week‑by‑week preparation guide leading up to the due date.  
- **Navigation menu:** Links to each major section of the site.  
- **Responsive layout:** Ensures the site works smoothly on phones, tablets, and desktops.

### Project 02 – Final MVP (Week 08)
- **Interactive checklist:** Users can check off items as they prepare.  
- **Partner support guide:** A dedicated section with tips, reminders, and responsibilities for partners.  
- **Newborn essentials page:** A detailed list of items needed for the first week at home.  
- **Calming design enhancements:** Soft colors, icons, and improved layout for a more supportive experience.  
- **Optional additions:** A contraction timer, printable PDFs, or a customizable birth plan template.

## 3. Tools and Technologies

- **Code Editor / Development Environment:**  
  I will use **Visual Studio Code** because it offers strong extensions, Git integration, and a smooth workflow.

- **Framework / Approach:**  
  I will build the site using **HTML, CSS, and JavaScript from scratch**, giving me full control over structure, styling, and interactive features.

- **Hosting / Deployment:**  
  I will publish the site using **GitHub Pages**, which provides free hosting, automatic deployment, and seamless integration with my repository.

- **AI Tools:**  
  I will use **Copilot** to help generate starter code, refine layout ideas, and assist with troubleshooting during development.

- **Other Tools:**  
  I may use **Figma** or simple sketching tools to plan the layout, and small libraries like Font Awesome for icons. GitHub will serve as my version control system.

---

## 4. Risks and Unknowns

One risk is that I have not built an interactive checklist or timeline before, so implementing those features may require extra learning. Another unknown is how long it will take to refine the design into a calm, supportive experience that fits the theme of childbirth preparation. I also need to ensure the scope remains manageable so I can complete all planned features within the project timeline. Finally, deploying through GitHub Pages may require troubleshooting if I encounter configuration issues.
